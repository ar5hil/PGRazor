# PGRazor v0.1.0-alpha.5

Install **PGRazor.apk** below. It appears as **Pokémon GO** in the launcher and updates alpha.4 using the same signing key.

## Added

- **Automation Engine Selection:** Choose between **PGRazor VGP** and **Rasiel native** engines. Switching engines automatically stops the inactive one.
- **Rasiel native automation:**
  - Native Auto Catch and Auto Spin.
  - Configurable ball selection (Poke, Great, Ultra).
  - Native throw grade selection (Nice, Great, Excellent).
  - Berry selection for native catches.
  - **Screen-free catches:** Direct throw mode for native automation.
- **Auto gym feed:** Automatically feeds owned berries to gym defenders (up to 10 per gym every 30 minutes).
- **Field research automation:**
  - Auto claim completed field research.
  - **Research filter:** Define rules using `task|reward` grammar to determine which research to claim or remove.
- **Quick menu updates:** Direct toggles for Auto Catch and Auto Spin with engine status indicators.

## Validation

Native automation, gym feeding, and research filtering are only active in builds using the `--quick-close` script. Settings status correctly reflects build capability. Basic persistence and logic have been verified via regression tests. User validation on a physical device is required for native hook stability and field research matching.
